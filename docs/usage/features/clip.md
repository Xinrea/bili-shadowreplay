# 切片

切片功能允许你从录播视频中截取精彩片段，并进行编辑和投稿。

## 生成切片

### 从录播生成切片

1. 在直播间列表中，点击录播卡片进入录播预览页面
2. 在视频播放窗口中，使用快捷键或按钮设定切片区间：
   - 按 `[` 键设定切片起点
   - 按 `]` 键设定切片终点
   - 按 `q` 键跳转到切片起点
   - 按 `e` 键跳转到切片终点
   - 按 `c` 键清除当前选区
3. 输入切片标题（可选，不输入则自动使用时间戳命名）
4. 点击「生成切片」按钮或按 `g` 键生成切片

视频轨道上会显示绿色的选区标记，表示当前选定的切片区间。

### 从外部导入视频

你也可以导入外部视频文件作为切片：

1. 在切片页面点击「导入视频」按钮
2. 选择视频文件
3. 系统会自动转换为项目格式并添加到切片列表

## 管理切片

### 查看切片列表

在切片页面可以查看所有生成的切片，支持：

- 按直播间号筛选
- 按标题、时长、大小、创建时间等排序
- 批量选择和删除

### 切片操作

对每个切片，你可以进行以下操作：

- **播放**：打开切片预览窗口
- **编辑备注**：为切片添加备注信息
- **导出**（仅 Web 版）：下载切片到本地
- **删除**：删除切片文件

### 二次切片

你可以对已生成的切片进行二次剪辑：

1. 点击切片的「播放」按钮打开预览窗口
2. 使用相同的快捷键设定新的切片区间
3. 生成新的切片

这样可以对精彩片段进行进一步的精细化剪辑。

## 切片预览窗口

在切片预览窗口中，你可以：

- 查看视频封面和基本信息
- 编辑字幕（参见 [字幕功能](./subtitle.md)）
- 压制弹幕（参见 [弹幕功能](./danmaku.md)）
- 编辑投稿信息并上传到 B 站

### 快捷键说明

按 `h` 键可以展开/收起快捷键说明面板。主要快捷键包括：

- `Space`：播放/暂停
- `←` / `→`：后退/前进 5 秒
- `[` / `]`：设定选区开始/结束
- `q` / `e`：跳转到选区开始/结束
- `g`：生成切片
- `c`：清除选区

## 投稿功能

生成切片后，你可以直接在预览窗口进行投稿：

1. 在预览窗口右上角选择要使用的账号
2. 填写投稿信息：
   - 标题
   - 简介
   - 标签
   - 分区
   - 封面（支持在线编辑）
3. 点击「投稿」按钮上传到 B 站

投稿成功后，切片列表中会显示对应的 BV 号，点击可直接跳转到 B 站查看。

## 注意事项

> [!WARNING]
> - 切片生成需要一定的时间，具体取决于切片长度和系统性能
> - 删除切片后无法恢复，请谨慎操作
> - 批量删除会同时删除所有选中的切片

> [!TIP]
> - 切片时建议预留 1-2 秒的缓冲时间，避免剪掉开头或结尾的重要内容
> - 可以通过编辑备注功能为切片添加标记，方便后续管理
> - 投稿前建议预览一遍切片，确保内容完整
