# 素材与切片

从录播中截取的视频片段称为**素材**；**切片**是由一个或多个素材组成的剪辑工程，在切片中完成裁剪、字幕和弹幕压制后导出投稿。

## 素材

### 从录播生成素材

1. 在直播间列表或录播页面进入录播预览窗口
2. 在时间轴上设定选区：
   - 按 `[` 键设定选区起点
   - 按 `]` 键设定选区终点
   - 也可以使用「新建选区」或右侧「智能推荐」添加选区
3. 点击「生成素材」，确认后每个已激活的选区会生成一个素材

生成素材时直接复制视频流，不重新编码，速度很快。为了不在关键帧之间切断画面，素材会从选区起点前最近的关键帧开始，因此可能比选区多出开头的一两秒，可以在切片中裁掉。

选区内的弹幕会和素材一起保存，录播被清理后，素材的弹幕仍然可用；素材本身不压制弹幕，在切片导出时可以选择压制。

勾选「同时新建切片」会按选区顺序把生成的素材放入一个新切片，便于直接剪辑和投稿。「修复编码」用于素材播放异常的情况，会重新编码素材。

### 从外部导入视频

在素材页面点击「导入视频」，选择视频文件后会作为素材加入列表（FLV 会自动转换为 MP4）。导入的视频没有弹幕。

### 管理素材

素材页面可以按直播间筛选和排序，对每个素材可以：

- **预览**：打开素材预览窗口，查看来源录播、录播区间和保存的弹幕
- **新建切片**：用这个素材新建一个切片并打开编辑窗口
- **编辑备注**、**导出**（仅 Web 版）、**删除**

选中多个素材后可以「用所选素材新建切片」，素材按创建时间排列。删除素材前会列出使用它的切片，删除后这些切片中对应的片段会被移除。

## 切片

切片页面列出所有切片，显示时长、片段数、导出状态和投稿状态。点击切片打开切片编辑窗口，也可以点击「新建切片」从空白开始。

### 切片编辑窗口

窗口左侧是素材库，中间是预览和时间轴，右侧是字幕、片段、导出和投稿面板。所有修改都会自动保存。

- **添加素材**：把素材从素材库拖到时间轴上的任意位置，或点击素材右侧的「＋」添加到末尾。素材已识别过字幕时，会一并带入
- **调整顺序**：拖动片段到新位置
- **裁剪**：拖动片段的左右边缘调整入点和出点，也可以在「片段」面板中输入精确时间；拖动时会吸附到播放头和其它片段的边界，按住 `Shift` 可暂时关闭吸附
- **分割**：按 `Ctrl` / `⌘` + `B` 或点击「分割」在播放头处把片段一分为二
- **删除**：选中片段或字幕后按 `Delete`
- **撤销 / 重做**：`Ctrl` / `⌘` + `Z`、`Ctrl` / `⌘` + `Shift` + `Z`

片段在主轨道上首尾相接播放，删除或裁剪片段后，后面的片段会自动前移。字幕跟随所在的片段：移动、裁剪片段时字幕随画面一起移动，超出片段范围的字幕会被隐藏，重新拉长片段后会恢复显示。字幕的编辑方法参见 [字幕功能](./subtitle.md)。

预览直接播放素材文件并在片段之间无缝切换，字幕预览与导出时使用同一份 ASS 脚本。

### 导出

在「导出」面板中可以选择是否压制弹幕，然后点击「导出切片」。导出会按时间轴把各片段统一缩放到 1920×1080 后拼接，并压制字幕和弹幕；任务在后台队列中执行，可以在任务中心查看进度或取消，期间可以继续编辑或关闭窗口。

导出后再修改切片，导出状态会变为「需重新导出」。只包含一个完整素材、没有字幕和弹幕的切片无需导出，投稿时直接使用素材文件。

## 投稿

在切片编辑窗口的「投稿」面板中：

1. 设置封面（默认使用第一个素材的缩略图，可以点击「创建新封面」从视频画面制作）
2. 填写标题、分区、简介、标签和动态
3. 选择投稿账号后点击「投稿」

投稿信息按切片保存，同一直播间的新切片会沿用上一次填写的内容。切片需要先导出才能投稿。投稿成功后，切片列表中会显示对应的 BV 号，点击可直接跳转到 B 站查看。

## 旧版本数据

升级后，原来的每个切片会成为一个素材，并自动生成一个只包含该素材的切片，原有的标题、备注、投稿状态和字幕都会保留在切片中。

## 注意事项

> [!WARNING]
> - 删除素材或切片后无法恢复，请谨慎操作
> - 导出切片需要重新编码，耗时取决于切片长度和系统性能

> [!TIP]
> - 选区可以稍微放宽，在切片中再精确裁剪
> - 可以通过备注为素材和切片添加标记，方便后续管理
> - 投稿前建议在切片编辑窗口中完整预览一遍
