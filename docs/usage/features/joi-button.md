# 轴伊按钮投稿

ShadowReplay 可以把直播切片直接提交到自托管的轴伊按钮站点。首次使用需要在“账号”页面添加一个轴伊按钮账号；之后在切片预览窗口的“快速投稿”中选择对应站点即可。

## 添加站点账号

1. 打开“账号” → “添加账号” → “轴伊按钮”。
2. 填写自托管站点地址，例如 `https://button.example.com`。
3. 点击“获取验证口令”，打开返回的直播间，把口令作为弹幕发送。
4. 等待验证完成。验证通过后，站点令牌才会保存为本地账号。

可以复制口令手动发送；如果本地已经配置 B 站账号，也可以使用“一键发送”。一键发送使用验证响应中的房间号，不使用当前录播的房间号。连接暂时不可用时，页面会保留口令并继续轮询，避免把站点故障误报成发送失败。

## 投稿切片

在切片预览窗口选择“轴伊按钮”后，ShadowReplay 会从站点的投稿契约读取当前分组和语言。不要在客户端预设这些选项，因为站点可能已经停用某个分组或新增了语言。

投稿表单包含：

- 切片名称、说明、备注、说明语言和分组；
- 来源类型（直播或视频）、来源标题、日期、时间和来源链接。

来源信息会根据切片填入初始值，但所有字段都可以修改。来源时间按 `mm:ss` 发送为秒数；来源链接可以留空。提交前会在本地预估音频大小，超过 5 MB 的切片会提示裁短到约 3 分半以内，不会先上传再失败。

投稿音频使用 192 kbps、44.1 kHz，并保留源声道；如果本机没有 MP3 编码器，会尝试使用站点接受的 m4a 格式。临时音频只用于当前请求，完成或失败后都会清理。

## 状态提示

投稿期间表单内容不会因为重试或令牌过期而清空。站点限流会按 `Retry-After` 自动排队重试，自动重试有次数上限；如果仍被限流，页面会提示稍后手动重新投稿。令牌过期时需要重新验证账号；存储空间不足时请联系站点管理员。其他错误会保留站点返回的原始信息。

站点地址、访问令牌和令牌到期时间保存在 ShadowReplay 的本地数据库中。访问令牌不会显示在账号列表，也不会写入日志或文档。
