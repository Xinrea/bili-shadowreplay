> [!WARNING]
> B 站、抖音直播间需要先配置对应平台账号；斗鱼、虎牙、快手、TikTok、Twitch 和 YouTube 可直接添加。Twitch 使用公开接口和匿名聊天连接，不需要配置账号。

## 添加直播间

### 手动添加直播间

你可以在 BSR 直播间页面，点击按钮手动添加直播间。你需要选择平台，并输入直播间号。

直播间号通常是直播间网页地址尾部的数字，例如 `https://live.bilibili.com/123456` 中的 `123456`，或是 `https://live.douyin.com/123456` 中的 `123456`。斗鱼支持输入数字房间号或 `https://www.douyu.com/<房间号或短名>` 链接；部分直播间（包括使用靓号的赛事房间）的网址数字可能不是内部房间号，例如 `6657`。BSR 会尝试解析为内部房间号，所以添加后列表里显示的数字可能和网址里的不同。

抖音直播间比较特殊，当未开播时，你无法找到直播间的入口，因此你需要当直播间开播时找到直播间网页地址，并记录其直播间号。

抖音直播间需要输入主播的 sec_uid，你可以在主播主页的 URL 中找到，例如 `https://www.douyin.com/user/MS4wLjABAAAA` 中的 `MS4wLjABAAAA`。

Twitch 直播间请输入频道登录名（例如 `ninja`、`@ninja`），也可以直接粘贴 `https://www.twitch.tv/ninja`。Twitch 弹幕通过公开 IRC 连接获取。

### 接收 OBS 的 RTMP 推流

在「添加直播间」中选择「RTMP 推流」，只需填写房间名称。无需添加平台账号；创建时自动分配一个空闲端口、随机生成推流密钥，并立即启动内置 RTMP 服务。

1. 在 OBS「设置 → 推流」中将服务设为「自定义」。
2. 打开房间卡片右上角的菜单，选择「状态」，在状态窗口的「RTMP 推流」中查看地址和密钥。将推流地址（例如 `rtmp://127.0.0.1:52137/live`，以实际分配端口为准）填入 OBS 的服务器，并复制推流密钥。
3. 推荐使用 H.264 视频、AAC 音频及 2 秒关键帧间隔，点击「开始推流」。
4. BSR 自动录制，可以像其他直播间一样实时回放、查看录制记录和生成切片。RTMP 房间不采集平台弹幕。

没有推流时，房间显示「未开播 / 未录制」；OBS 开始推流后显示「已开播 / 正在录制」，停止推流并完成录制收尾后恢复「未开播 / 未录制」。房间卡片和「房间状态」会同步更新。

服务默认监听所有 IPv4 网卡。OBS 在其他电脑上运行时，请将地址中的主机替换为 BSR 所在电脑的局域网 IP，并放行对应的 TCP 端口；Docker 部署需要额外映射自动分配的端口。每个 RTMP 房间使用不同端口，端口和密钥随房间保存，重启 BSR 后保持不变。房间菜单中的「状态」可随时查看和复制推流信息，以及查看录制统计和录播日历。

每个房间同时接受一路推流，并校验应用名 `live` 和推流密钥。停止推流会完成当前录制，房间继续等待下一次连接；重连会创建新的录制记录。停用房间会断开当前推流，保留监听端口并拒绝新推流，启用后可让 OBS 重连。移除房间或退出程序时释放端口。请仅向需要推流的人提供密钥。

## 启用/禁用直播间

你可以点击直播间卡片右上角的菜单按钮，选择启用/禁用直播间。

- 启用后，当直播间开播时，会自动开始录制
- 禁用后，当直播间开播时，不会自动开始录制

## 移除直播间

> [!CAUTION]
> 移除直播间后，该直播间相关的所有录播都会被删除，请谨慎操作。

你可以点击直播间卡片右上角的菜单按钮，选择移除直播间。
