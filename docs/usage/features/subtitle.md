# 字幕

BSR 提供了完整的字幕功能，包括 AI 自动生成、手动编辑和压制输出。字幕在[切片](./clip.md)编辑窗口中编辑，导出切片时压制。

## 生成字幕

### AI 自动生成

BSR 内置了 Whisper 语音识别模型，可以自动为视频生成字幕：

1. 在切片编辑窗口的「字幕」面板中，点击「AI 字幕」按钮
2. 选择是否覆盖已有字幕的片段、是否忽略缓存重新识别，然后开始
3. 等待识别完成（时长取决于素材长度），字幕会按片段范围出现在时间轴上

识别按素材进行，每个素材只识别一次，结果会缓存在素材中；同一素材被多个片段或多个切片使用时不会重复识别，之后把素材加入其它切片时也会自动带入已识别的字幕。开启「自动生成字幕」后，新生成的素材会自动识别。

详细配置参见 [Whisper 配置](../../getting-started/config/whisper.md)。

### PowerLive 云端字幕

1. 在桌面版「设置」的「PowerLive 账号」中点击「登录 PowerLive」。
2. 在系统浏览器中完成登录，软件会自动唤回并显示账号名称；也可点击网页上的「返回软件」。
3. 将字幕生成器选为「PowerLive」，之后的字幕生成和录播总结会使用该账号的额度。

设置中的账号信息会显示剩余额度，并在设置页每分钟自动刷新。登录完成、重新进入设置或恢复联网时也会更新，还可点击额度旁的刷新图标立即查询。「PowerLive 控制台」按钮可打开网页控制台管理账号。

无需填写 API Key。登录凭据由软件后端保存，默认使用系统钥匙串支持的加密存储，并自动刷新。可以在设置中取消等待中的登录或退出登录；如需切换账号，请先退出再重新登录。登录窗口三分钟内未完成会超时，可重新打开。若退出登录时网络不可用，可点击「仅清除本地登录」删除本机凭据；该操作不会撤销远端授权。

此功能需要支持 BSR 账号登录的 PowerLive 服务端版本。网页控制端不提供本机浏览器登录入口，请在桌面版设置中完成登录。

### 手动添加字幕

你也可以手动添加和编辑字幕：

1. 把播放头移到要添加字幕的位置，点击预览下方的「字幕」按钮
2. 在右侧字幕列表中输入文本
3. 拖动字幕块的边缘调整开始/结束时间
4. 拖动字幕块中间部分移动整个字幕

## 编辑字幕

### 时间轴编辑

在切片编辑窗口的底部时间轴上，你可以：

- **查看字幕块**：字幕以蓝色块的形式显示在时间轴上
- **选中字幕**：点击字幕块即可选中（白色描边），打轴快捷键作用于选中的字幕
- **调整时间**：拖动字幕块的左右边缘调整开始/结束时间
- **移动字幕**：拖动字幕块中间部分移动整个字幕段
- **吸附对齐**：拖动时字幕的边缘会吸附到其它字幕的开始/结束时间、片段边界和播放头，让相邻字幕首尾相接、既不留缝隙也不重叠；吸附时时间轴上会出现一条黄色参考线，按住 `Shift` 拖动可暂时关闭吸附
- **添加字幕**：点击字幕列表中的「+」按钮在当前位置后添加新字幕
- **删除字幕**：点击字幕项旁边的删除按钮，或选中后按 `Delete`

字幕属于它开始时所在的片段：移动、裁剪片段时字幕随画面一起移动；字幕的边缘只能在所属片段的范围内调整，整体拖到另一个片段上会改为属于该片段。超出片段范围的字幕会被隐藏，拉长片段后会重新显示。

时间轴支持缩放功能，可以通过滑块或按住 `Ctrl` / `⌘` 滚动鼠标滚轮调整时间轴的缩放比例，方便精确编辑。

### 字幕文本编辑

在右侧字幕列表中：

- 点击字幕序号可选中该字幕并跳转到对应的视频位置
- 直接编辑字幕文本，按 `Enter` 或 `Esc` 退出编辑
- 当前播放位置的字幕会高亮显示

### 打轴快捷键

打轴快捷键与 Aegisub 的默认键位一致，作用于选中的字幕；没有选中字幕时，作用于播放位置所在的字幕。

| 快捷键 | 功能 |
| --- | --- |
| `Z` / `X` | 选中上一条 / 下一条字幕，并跳到其开始位置 |
| `S` | 播放选中字幕 |
| `Q` / `W` | 播放选中字幕开始前 / 结束后 500ms |
| `E` / `D` | 播放选中字幕开头 / 结尾 500ms |
| `Ctrl` + `3` | 将选中字幕的开始时间设为当前播放位置 |
| `Ctrl` + `4` | 将选中字幕的结束时间设为当前播放位置 |

macOS 上也可以用 `⌘` 代替 `Ctrl`。在字幕输入框中编辑时快捷键不生效。点击播放控制栏最右侧的「?」按钮可以随时查看全部快捷键。

### 多层字幕支持

BSR 支持在同一时间显示多条字幕，适用于：

- 双语字幕
- 人物标注
- 补充说明

字幕会自动进行分层显示，避免重叠。

## 字幕样式

点击「样式设置」按钮可以自定义字幕样式。

**预设样式**提供经典白字、醒目粗体、综艺黄字、半透明底框、电影细字、粉色描边、霓虹蓝光和顶部标题等常用效果，点击即可套用，并保留当前选择的字体。套用后仍可继续微调。

「常用设置」包括：

- **字体**：从执行压制的机器已安装的字体中选择，可按英文名或中文名搜索；含中文字形的字体排在前面。新安装的字体需重启应用（或 Docker 容器）后才会出现在列表中
- **字号**、**粗体**、**斜体**
- **文字颜色**、**描边颜色**、**描边宽度**、**阴影距离**；使用半透明底框时，描边颜色和宽度分别对应底框颜色和底框边距。修改颜色会保留原有透明度
- **位置**：画面九宫格位置
- **边距**：调整字幕与画面左右及上下边缘的距离

字号、描边和边距使用固定的 **1920 × 1080 ASS 脚本坐标**，会随视频画面缩放。原有保存的样式会自动转换到这套坐标，保持原来的相对尺寸和位置。

切换到「ASS 样式代码」可以直接编辑标准 `[V4+ Styles]` 段的 `Format:` 和 `Style:` 行，包括透明度、粗体、斜体、缩放、字距、旋转、阴影等高级属性。常用设置和代码编辑相互同步，修改常用设置会保留其他高级字段。每份样式只使用一个 `Style:`；字幕文本和时间仍在时间轴中编辑。

样式窗口中的示例通过与压制相同的原生 Skia 渲染器绘制。代码有误时会显示原因，并暂停预览和保存；修正后可继续查看效果。点击「保存并应用」后，样式会保存到当前切片并立即应用于预览，同时作为该直播间新切片的默认样式。点击「取消」、关闭按钮或窗口外部会放弃本次修改。

## 压制字幕

字幕在导出切片时压制到视频中（参见 [素材与切片](./clip.md#导出)）。导出任务与素材生成、完整录播生成共用队列，默认依次执行，最多可有 20 个任务等待；等待中和正在执行的任务均可在任务中心取消。

每次导出使用提交时的字幕和样式，之后的编辑不会改变已提交的任务；导出后修改字幕，切片会提示需要重新导出。

> [!NOTE]
> 导出切片需要一定的时间，具体取决于切片长度和系统性能。导出过程中可以继续进行其他操作。

## 字幕保存

字幕随切片自动保存，无需手动保存。AI 识别的结果以 SRT 格式缓存在素材文件旁（与视频同名的 `.srt` 文件）。

## 实时预览

编辑字幕时，视频画面上通过 WebAssembly 版 libass 实时显示字幕效果，包括：

- 字幕文本
- 字幕样式
- 多层字幕布局

预览和 FFmpeg 压制使用同一份 ASS 脚本，包括时间、文本、层级和样式，减少 CSS 模拟与实际压制之间的差异。

预览会从执行压制的机器加载字体，网页控制端也使用该机器的字体。指定字体缺失时会提示并使用替代字体；应在压制机器上安装需要的字体。两端使用相同的字体文件及字重，有助于保持字形、字宽和换行一致。字体缺少的中文字符会按压制机器的系统使用回退字体：Windows 为微软雅黑，macOS 为苹方，Linux 和 Docker 优先使用 Noto Sans CJK，其次为文泉驿；预览使用同一回退字体。不同 libass 版本和视频显示缩放仍可能产生细微差别，压制前建议检查预览中的字体是否符合预期。

## 注意事项

> [!TIP]
> - AI 生成字幕后建议手动检查和修正，特别是专有名词和口音较重的部分
> - 字幕时间建议与语音完全对齐，避免提前或延后
> - 导出前建议预览确认效果；导出的视频中字幕无法再次编辑，但切片中的字幕可以修改后重新导出
> - 字幕样式设置会影响所有字幕，建议在开始编辑前先设置好样式
