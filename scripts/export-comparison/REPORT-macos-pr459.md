# macOS 当前实现与 PR #459：异步交接后的同批复测

2026-10-31，仅在 macOS / M2 Max 上重新运行两种实现。**当前实现尚未追平 #459；本次三组对照中，#459 均更快且耗时更稳定。**

当前实现中位数 **48.811 s**，#459 为 **38.218 s**；当前多用 **10.592 s（27.72%）**，#459 吞吐为当前的 **1.277×**。以当前耗时为分母，达到 #459 本次水平还需减少约 **21.70%**。这些数字全部来自本次同批对照，没有混入此前结果。

## 测量方法

- 同一台 M2 Max，12 CPU / 38 GPU、64 GiB，macOS 27.0.1。两边同源 FFmpeg 9.0.2；当前使用 MoltenVK 1.4.2。Windows 没有访问或重测。
- 当前媒体实现：`5b8df1575f8ea91d8ad67adc9274e0ae77a3a541`，包含默认自动解码线程和默认三帧异步 VideoToolbox 交接。工作区 `aa16b52c` 在此基础上只有报告改动。
- [#459](https://github.com/Xinrea/bili-shadowreplay/pull/459)：`c73c7aaff9b9dd9abb561c90a48f19b2d6374112`。开跑前通过 GitHub 再次确认 head；其生产源码原样保留。
- 复用已经构建的 release 二进制，核对当前 115 个非 Markdown 源文件、#459 的 28 个源码／资源文件、runner 和 Cargo.lock、二进制及运行库哈希，再重新执行全部导出与校验。没有改动两边媒体算法，也没有在计时期间构建。
- 同一段连续五分钟 Big Buck Bunny 视频，1920×1080 / 60 FPS / 18,000 帧；每秒 16 条文字 + 4 条 PNG 表情，共 6,000 条，滚动 8 秒。两段视频和 16 个场景文件逐项核对 SHA-256。
- HEVC、速度优先、10 Mbps，复制源 AAC；其余保留各自产品默认编码策略。当前使用 MediaPlan + Skia Vulkan / MoltenVK + libplacebo + VideoToolbox；#459 使用其 Skia Metal + 专用 compute shader + VideoToolbox。
- 两边先各预热 600 帧，然后交替三组：“当前→#459、#459→当前、当前→#459”。每台机器同时只有一个基准导出或内容校验任务；全部正式运行关闭 profiler、API capture 和 Vulkan validation。
- 计时为进程启动至成功退出，包含场景解析、初始化、能力探测、真实解码／渲染／编码／封装及关闭。素材／弹幕调度准备、GUI/V8/语音启动、项目分片缓存、上传和输出校验不计时。这是单视频弹幕压制媒体路径的比较。

预热不进入中位数。三次重复用于观察本机波动，不构成统计置信区间，也不代表其他芯片、分辨率或弹幕密度下的差距。

当前三次为 44.225–51.447 s，#459 为 38.115–38.318 s；当前最快的一次也慢于 #459 最慢的一次。当前实现此次波动明显大于[上一轮交接测试](REPORT-handoff.md)的 44.697–45.175 s，所有样本均保留。本轮没有同步采集阶段计时、设备频率或其他系统负载，不能确定波动原因，也不应将 27.72% 当作固定性能差距。此前用跨批次数据估计的约 17.8% 不能替代这次同批结果。

## 输出与资源

| 实现 | 最大 GOP 间隔 | has_b_frames | 视频码率中位数 | 文件大小中位数 |
| --- | ---: | ---: | ---: | ---: |
| 当前实现 | 120 | 0 | 10.039 Mbps | 366.27 MiB |
| #459 | 240 | 2 | 10.058 Mbps | 367.10 MiB |

`has_b_frames` 是解码重排相关字段，不是 B 帧总数；逐次 I/P/B 数量在回执中。GOP、重排和编码默认策略仍不同。码率接近和内容校验通过，均不能证明两者编码画质等价；这是产品默认参数的速度比较。

以下各列分别取 `/usr/bin/time -l` 三次测量的中位数；CPU 秒为所有线程的 user + system，平均核数先按每次运行的 CPU 秒 / 墙钟计算。RSS 和 physical footprint 是不同指标，也不等于完整 GPU 内存或能耗。

| 实现 | 总 CPU 时间 | 平均 CPU 核数 | 峰值 RSS | 峰值 physical footprint |
| --- | ---: | ---: | ---: | ---: |
| 当前实现 | 132.18 CPU-s | 2.74 | 305.25 MiB | 542.56 MiB |
| #459 | 110.97 CPU-s | 2.90 | 311.64 MiB | 461.09 MiB |

#459 在有弹幕场景、逻辑 CPU ≥12 时原本就会启动一个高 QoS 忙等线程，不做视频工作；本机满足条件。本次保留这个行为，其开销包含在 #459 的 CPU 统计中。没有单独禁用该线程做消融实验。

本次只测量完整链路，没有为 #459 添加阶段探针。因此不能把剩余差距定量归因于 Metal/Vulkan、libplacebo、线程调度、编码设置或忙等线程中的某一项。[当前实现的阶段诊断](REPORT-handoff.md)来自前一轮独立实验。
