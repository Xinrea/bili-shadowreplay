These tiny fixtures contain generated red/blue patterns, with no third-party
content. The first frame is 16×12 RGBA `[220, 40+x*5, 25, alpha]`, with alpha
128 in the left half and 255 in the right half. The second frame replaces red
220 with 20 and blue 25 with 220. GIF quantizes colors/alpha; JPEG is opaque.

- `animated.png`: two-frame APNG, 2 fps, infinite loop.
- `animated.gif`: two-frame GIF, 2 fps, infinite loop.
- `alpha.webp`: first frame encoded with `libwebp -lossless 1`.
- `animated.webp`: both frames encoded with `libwebp_anim -lossless 1 -loop 0`.
  It deliberately exercises rejection/fallback under the legacy image format
  whitelist (which excludes the newer `webp_anim` demuxer).
- `still.jpg`: the first frame encoded with MJPEG's default quality.

The ordinary PNG, scale, ICC and decompression-bomb fixtures are generated by
the tests themselves using PNG chunks and zlib, so core tests require no CLI.
